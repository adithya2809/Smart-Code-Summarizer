# 🎬 Netflix Clone — Frontend Project

A pixel-accurate clone of the Netflix India landing page built using HTML, CSS, and JavaScript. This project replicates the core UI and interactions of the Netflix homepage.

## ✨ Features

- **Responsive Design** — works on mobile, tablet, and desktop
- **FAQ Accordion** — click to expand/collapse answers, only one open at a time
- **Email Validation** — checks for valid email format before proceeding
- **Trending Row** — horizontally scrollable show thumbnails with hover zoom
- **Hero Section** — full-screen background with overlay and gradient border
- **"More Reasons" Cards** — 4-column grid with gradient cards and icons
- **Footer** — multi-column link grid matching Netflix's layout

## ⚙️ How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/netflix-clone.git
   ```
2. Open the folder and double-click `index.html`
3. It opens directly in your browser — no server needed

## 📱 Responsive Breakpoints

| Screen Size | Layout |
|---|---|
| > 1200px | Full 4-column grid |
| 992px – 1200px | 3-column grid |
| 768px – 992px | 2-column grid |
| < 768px | Single column, stacked input |
| < 480px | Compact mobile layout |

---

## 🧠 JavaScript Features

- **FAQ Toggle** — `toggleFaq()` opens one answer at a time and rotates the + icon to ×
- **Email Validation** — validates on button click, shows inline error message
- **Event Listeners** — Sign In and Language buttons wired with `addEventListener`
